# **Student Grade Calculator**



#### **1. Introduction**



The Student Grade Calculator is a Python-based program that accepts marks for multiple subjects and calculates the total marks, percentage, and grade of a student.



#### **2. Objective**



The main objective of this project is to practice Python conditions, arithmetic operations, user input, and input validation.



#### **3. Technologies Used**



\- Python

\- IDLE

\- GitHub



#### **4. Project Description**



The program accepts marks for five subjects:



\- Python

\- SQL

\- HTML

\- CSS

\- JavaScript



The program calculates the total marks and percentage and assigns a grade based on predefined conditions.

#### 

#### **5. Features**



\- Accepts student name

\- Accepts marks for multiple subjects

\- Validates marks between 0 and 100

\- Calculates total marks

\- Calculates percentage

\- Assigns grade

\- Displays student result

\- Handles invalid marks



#### **6. Grade Criteria**



##### &#x20; **Percentage   Grade** 

&#x20;      90 - 100           A+    

&#x20;      80 - 89            A     

&#x20;      70 - 79            B     

&#x20;      60 - 69            C     

&#x20;      50 - 59            D     

&#x20;      40 - 49            E     

&#x20;      Below 40           F     



#### **7. Python Program**



The main Python program is available in:



`student\_grade\_calculator.py`



#### **8. Sample Result**



Example:

Student Name: Madeena Beebi

Total Marks: 423 / 500

Percentage: 84.6%

Grade: A



#### **9. Validation**



The program checks whether marks are between 0 and 100.



If the user enters a value outside this range, the program displays an error message and asks for the marks again.
